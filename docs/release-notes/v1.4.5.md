# Aphrodite 1.4.5 (Plugin 2.1.3)

A configuration-template refresh release. No engine or FFI changes; binary
`1.4.4 → 1.4.5`, plugin stays on `2.1.3`.

## What's new

- **Provider-agnostic config template.** The shipped `aphrodite.toml` template
  drops provider-specific defaults in favor of ~250 lines of neutral,
  provider-agnostic configuration. API URL and model are no longer baked in -
  set them via the `APHRODITE_API_URL` / `APHRODITE_MODEL` env vars or your
  proxy's own upstream configuration.
- **Cleanup.** An internal headroom-publish reference document was removed from
  the tree.
