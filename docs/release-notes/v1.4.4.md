# Aphrodite 1.4.4 (Plugin 2.1.3)

A setup hotfix release. Binary `1.4.3 → 1.4.4`; the plugin stays on `2.1.3`.

## What's new

- **Setup completes without the core dylib.** `cargo install` setup no longer
  fails when the `libaphrodite_hermes` dylib cannot be produced at build time.
  The dylib is best-effort in the setup path - the plugin downloads it at
  runtime from the release assets instead.
- **Formatter alignment.** The embedded plugin shim template is synced
  byte-identical with the live formatter-aligned `__init__.py`, and the ruff
  formatter config explicitly excludes the templates directory from
  reformatting.
