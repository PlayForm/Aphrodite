# Aphrodite 1.4.3 (Plugin 2.1.3)

A feature release: a directives-path override, the full plugin hardening layer
(Windows multi-home dylib reuse, side-effect-free PID probe, install-flow
auto-download), and real-corpus benchmark tooling. No CCR engine changes;
binary `1.4.2 → 1.4.3`, plugin `2.1.2 → 2.1.3`.

## What's new

- **Directives override.** `APHRODITE_DIRECTIVES_DIR` overrides the directives
  discovery path and is checked before any other candidate, with
  intentional-empty semantics - setting it to an empty value is respected
  rather than silently ignored.
- **Install auto-download.** The plugin downloads the matching binary release
  asset automatically when needed; set `APHRODITE_NO_AUTO_DOWNLOAD` to opt out.
  `download.sh` uses a POSIX `od` magic check instead of `xxd`, and a silent
  proxy failure now surfaces a captured stderr with an API-key hint.
- **Windows multi-home dylib reuse.** The proxy pair and dylib state are shared
  across multi-home loads instead of being duplicated per home, and the PID
  probe that guards dylib selection is side-effect-free.
- **Benchmark tooling.** `benchmark-eval.py` was overhauled and a new
  `benchmark-report.py` produces per-corpus compression ratio, median/p95
  latency, per-content-type breakdown, and a JSON summary; a new Rust example
  (`bench_05_type_coverage`) exercises type coverage.
