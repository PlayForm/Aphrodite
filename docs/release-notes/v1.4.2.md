# Aphrodite 1.4.2 (Plugin 2.1.2)

A corrective release over v1.4.1 that stops the experimental `s2` crates from
breaking the dependency-advisory gate. No CCR engine or compression changes;
binary `1.4.1 → 1.4.2`, plugin `2.1.1 → 2.1.2`.

## Fixes

- **Dependency-advisory gate.** The experimental `s2` crates (`s2-probe`,
  `s2-navigate`) were a hard dependency of the proxy and transitively pulled in
  an unmaintained crate (`cgmath 0.18.0`, no safe upgrade) that failed the
  `cargo audit`/`cargo-deny` gate. `s2` is now an optional dependency behind
  the still-disabled `navigation` feature, and the `s2` crates are excluded
  from the release workspace. They remain in the repo as experimental code, and
  the `navigation` feature is still not shipped.
