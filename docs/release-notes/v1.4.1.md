# Aphrodite 1.4.1 (Plugin 2.1.1)

A corrective release over v1.4.0. No CCR engine or compression changes and no
crate renames - only the normal version bump (binary `1.4.0 → 1.4.1`, plugin
`2.1.0 → 2.1.1`).

## Fixes

- **CI build break.** A redundant `.into_iter()` in the config loader tripped
  `clippy::useless_conversion` under `clippy -D warnings` and failed the
  release build. The conversion was removed and the lint is clean again.
- **Release-tooling references.** Every leftover reference to the headroom core
  crate by its wrong bare name (`aphrodite-headroom`) was corrected to the
  actually published name (`aphrodite-headroom-core`) in the publish workflow
  and related references.
- **Plugin lint break.** Four `ruff` violations introduced by the v1.4.0
  hot-reload rework were corrected; `ruff check` on the plugin is clean again.
