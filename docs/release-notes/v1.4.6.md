# Aphrodite 1.4.6 (Plugin 2.1.4)

The flagship release: the chain-split CCR engine, honest previews end-to-end,
hardened FFI with generated bindings, a canonical runtime home with layout
self-heal, and installer removal. Binary `1.4.5 → 1.4.6`, plugin `2.1.3 →
2.1.4`.

## Chain-split CCR engine

A consequence-driven teaching loop with an adaptive chain-split threshold. The
engine learns where context is being wasted and splits chained shell commands
into fine-grained segments, so each command's output is compressed and
retrievable on its own.

The feature is **opt-in**: `chain_split = false` in the shipped config. Enable
it when you want fine-grained splitting of chained commands. Note that when it
is enabled, CCR markers can appear in redirected stdout.

## Honest previews

`preview_max_chars` now caps every rendered preview line on every path.
Precedence: `APHRODITE_PREVIEW_MAX_CHARS` env var > `[previews]
preview_max_chars` in TOML > default 120 (`0` = unlimited). The `ok`-collapse
is gone, the caller's type hint wins over the classifier, and the
build/error/lint/log arms surface real lines with a truthful `total_count` -
no more fabricated counts.

## Hardened FFI

The C-ABI layer is generated, not hand-written: cbindgen → ctypesgen →
`finalize_bindings.py`, validated by a pure-AST contract checker at build time.
Pointer widths are enforced on restypes, `free_string` argtypes are fixed, and
a subprocess smoke-test probes the dylib before ctypes loads it in-process - a
faulting dylib now degrades to "plugin disabled" instead of crashing the
gateway.

## Canonical runtime home

Every runtime artifact - binaries, directives, `ccr.db`, logs - now lives in
`~/.hermes/aphrodite`. The plugin directory is a thin registration shim, and
`layout_check.py` + `layout_schema.json` self-heal the layout at startup.
Legacy plugin-directory paths are kept as warning-flagged fallbacks so existing
installations keep working; migrate to `~/.hermes/aphrodite` when you see the
warning.

## Installer removal

`Maintain/install.sh` is removed from the release line. Installation is now
`download.sh` (POSIX) / `download.ps1` (PowerShell) inside the plugin. Before
downloading, the plugin validates the pinned `BINARY_VERSION` and warns when
the release has no assets.

## Configuration

- API key is optional at parse time and enforced when a proxy launches.
- Compression thresholds raised; engine compression enabled by default.
- Shipped config templates refreshed; provider-specific defaults dropped.
- `aphrodite setup` registers the plugin with Hermes and prints manual linking
  instructions.

## Removed

- `Maintain/install.sh` installer (replaced by `download.sh` / `download.ps1`).
- Internal fork-divergence documents and editor tooling configs no longer ship
  in the release tree.
- The `navigation` (S2) feature remains unshipped.
