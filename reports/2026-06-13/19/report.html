How it works — each run appends 6 inline + 4 proxy test cases to .hermes/tests/session_accumulator.json. The inline path uses headroom.compress() as a Python library call (zero HTTP), wrapping each new tool output in the accumulated session context. The proxy path sends HTTP requests through a running headroom proxy on port 8787, which applies SmartCrusher → Kompress → Cache before forwarding to DeepSeek v4-flash. Cache entries older than 40 messages are evicted. Use --reset to clear.

Inline — Python Library CCR

headroom.compress() called in-process on the accumulated session cache plus a new randomized tool output. CCR markers are LLM-native compressed references — the model understands them without decompression. Zero HTTP, zero API cost.

Pipeline: ContentRouter → SmartCrusher → CodeCompressor → Kompress → CCR strip → safety guard (reverts empty outputs only). Token counts come from headroom internals via CompressResult. Chars show the raw string length before and after — CCR markers are typically <100 chars regardless of input size.
