## Tool pitfalls hit on this run

- `write_file`/`patch` strip trailing newlines: byte-faithful restores required
  raw blob bytes; the first 6 files came out 1 byte short before correction.
- JSONC files (.vscode/settings.json) refuse write_file/patch (strict-JSON
  validation) — resolve via a literal-replace script or patch per hunk.
- GitHub PR three-dot diff showed the merge-base's old formatting as "before"
  (not a cache issue) — the two-dot compare shows the true divergence.
- Auto-committer swept in-session edits into 4431a77 mid-work; verify with
  git log / submodule status, not just git status.
