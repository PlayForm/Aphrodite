## 4. Clone-install flow - CONFIRMED (read-only verification, no gaps blocking)

```
git clone https://github.com/PlayForm/Aphrodite-Hermes.git
ln -s "$(pwd)/Aphrodite-Hermes" ~/.hermes/plugins/aphrodite   # or a profile plugins dir
hermes plugins enable aphrodite
hermes
```

1. **Discovery**: Hermes loads `~/.hermes/plugins/aphrodite/plugin.yaml` (standalone kind; 13 tools, 6 hooks, context engine declared).
2. **First load** (`register()` → `_load_dylib`, **init**.py:284): candidate search (`_DYLIB_PATH` env → plugin-dir `binaries/` → parent fallbacks, line 264) → `_ensure_binaries()` (line 480) runs `download.sh` when the binary or dylib is missing - no Rust toolchain needed. On v2.1.4 this target becomes `~/.hermes/aphrodite/binaries` via `APHRODITE_HERMES_DYLIB_PATH`.
3. **Download** (download.sh): version from `BINARY_VERSION` (1.4.6 after release), target auto-detected from `uname -sm`, assets fetched from `https://github.com/PlayForm/Aphrodite/releases/download/Aphrodite%2Fv<ver>/`, SHA-256 verified, native magic bytes validated, `chmod +x`.
4. **Load + register**: ctypes loads `libaphrodite_hermes.dylib` (hot-reload copies into `~/.hermes/aphrodite/hotreload`, reaped on start/exit, line 185); 6 hooks + 13 tools registered from the dylib JSON surface; skills probed from disk (see Gap 4); context engine opt-in via `APHRODITE_CONTEXT_ENGINE=1`.
5. **Proxy**: `_start_proxy()` (line 565) probes `:9797`/`:9798` health first (reuses an already-healthy pair), else launches `binaries/aphrodite`, polls health ≤5 s, writes `proxy-stderr.log` to `~/.hermes/aphrodite/`. **API key required**: `APHRODITE_API_KEY` or `aphrodite setup` or `api_key` in `~/.hermes/aphrodite/aphrodite.toml` - no keyless mode (documented plugin.yaml:38, README:46-65).
6. **Directives**: v2.1.3 - shipped `directives/` exposed via `APHRODITE_DIRECTIVES_DIR` (**init**.py:44); v2.1.4 - binary materializes its set into the runtime home at startup. Runtime management via `aphrodite_directive`.
