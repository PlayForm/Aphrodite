## What changed

### ruff.toml (repo root)

Note: the repo's ruff config file is `ruff.toml` (there is no `.ruff.toml`).
Verified before editing: it had NO per-file-ignores and NO exclude /
extend-exclude sections (the CI report's "extend-exclude for templates is
ABSENT" claim confirmed). Two sections added:

- `[lint.per-file-ignores]` for `plugins/aphrodite/_bindings.py` with the
  observed code family `N801, N802, N805, N811, N812, E402, F405, B009, SIM,
UP, C408` - the comment documents that the file is MACHINE-GENERATED by the
  FFI codegen pipeline (cbindgen -> ctypesgen ->
  `crates/aphrodite-hermes/codegen/finalize_bindings.py`, copy-on-change into
  the plugin submodule), never hand-edited. The six task-specified codes are
  present; SIM/UP/C408/N811/N812 are the codes actually observed in CI on past
  generated artifacts (SIM114/SIM101, UP008/C408/UP032/UP031/UP024/UP028) and
  are included so a future regeneration cannot re-break the CI ruff job.
- Top-level `extend-exclude = ["crates/aphrodite/templates"]` - that dir is
  the byte-identical plugin-shim template (drift-guard: `diff -q
plugins/aphrodite/__init__.py crates/aphrodite/templates/__init__.py`,
  enforced by `test_hermes_plugin_shim_template_matches_live`); a copy is not
  lintable source, byte identity wins.
  Pitfall fixed along the way: `extend-exclude` must sit at the TOP level,
  not after `[lint.per-file-ignores]` - a first draft placed it there and
  ruff rejected the TOML ("Unknown rule selector"); moved to top level and
  re-verified parse with ruff 0.15.17 AND 0.16.8 (the CI version).

### plugins/aphrodite/**init**.py:78 (N812)

The line was already the alias import (`from . import _bindings as
_GENERATED_BINDINGS` - the FFI commits added it); N812 fires BECAUSE the alias
is non-lowercase, which is deliberate (the name signals "generated module",
and `_GENERATED_BINDINGS` is referenced throughout the shim). Fix: `# noqa:
N812` on the same line; the rationale comment block directly above (lines
66-76) already explains the alias intent. Byte-identity rule applied
immediately: copied to `crates/aphrodite/templates/__init__.py`, `diff -q`
identical.
