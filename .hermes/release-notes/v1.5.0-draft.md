## Aphrodite v1.5.0 💋 Plugin v2.2.0

### Summary

v1.5.0 is the edition-2024 + atomization release: the crate moves to the
nightly toolchain / Rust 2024 edition (unsafe-attr exports, let-chains), the
flat `src/*.rs` files are promoted into per-item module trees (`state/`,
`preview/`, `directives/`, `marker/`, `resolve/`, `setup/`,
`struct_extract/`, `config/`), and the `chrono` dependency is dropped. It
adds the `aphrodite_debug` tool (per-session debug toggle that survives
dylib hot-reloads via a persisted session id), restructures the dev skill
system into canonical contract skills with a governance layer, and lands two
full inspection waves of correctness fixes across the state engine, catalog,
session lifecycle, hooks pipeline, proxy, retrieve, and config loader. The
README gains a real-world savings analysis with compression metrics.
Binary `1.4.6 → 1.5.0`, plugin `2.1.4 → 2.2.0`.

### Changes

- **Migration (edition-2024)**: workspace toolchain moved to latest nightly;
  `no_mangle` exports migrated to edition-2024 `unsafe` attribute syntax;
  nested conditionals converted to let-chains; `vendor/headroom` bumped to
  restore closure signatures; FFI contract checker taught the edition-2024
  attribute form; env-var test mutations wrapped in `unsafe`.
- **Refactor (atomization)**: flat module files converted to directory-based
  modules, then atomized into per-item module trees (`7cf8d2f`, `1c3f1f3`,
  `a81acab`, `3988513` preview); docs and scripts re-pointed at the new
  layout.
- **Feature (debug)**: `aphrodite_debug` tool toggles per-session debug
  output; session id persists across dylib hot-reloads and stays scoped to
  the current turn's session (`5e2ae8f`, `8e75ff3`, `e100b49`, `f1975ef`,
  `ff044dc`).
- **Refactor (deps)**: `chrono` dependency removed (`7b5ac47`).
- **Docs (skills)**: skill system restructured into canonical contract
  skills with a governance layer (`d49bbc2`); README savings analysis with
  real-world compression metrics (`cd858a0`).
- **Fix (inspection wave 1 - state/catalog/session)**: inline-store LRU
  promotion is O(1) via the `lru` crate order cache (was O(n) `retain`);
  `chain_split_enabled` struct default now matches the shipped config
  default (false); `recent_markers` is a `VecDeque` with O(1) front
  eviction; ring caps become named constants; `always_survive` counts only
  present sections (fixes context sections being dropped under budget
  pressure); catalog `by_type` is deterministic (`BTreeMap`); the file-delta
  summary selects genuinely new files (front of the deque, insertion-order
  display); `chain_split_min_segments` resets to the configured floor on
  session start; `post_llm_call` archives the largest marker of the turn,
  not merely the last; the catalog table reports entries beyond its 20-row
  window; directive truncation uses a consistent char-count unit.
- **Fix (inspection wave 2 - proxy/retrieve/config)**: poisoned
  `inline_ccr` lock returns HTTP 500 instead of a silent miss; `get_bool`
  accepts uppercase/mixed-case `TRUE`; a found-but-broken `aphrodite.toml`
  now warns instead of being skipped silently (both `load` and `load_from`);
  the missing-`$HOME` fallback warns instead of silently writing the CCR
  database to a volatile location; `body_wants_stream` gets a byte-exact
  fast path; content-type detection requires error markers at the start of
  the first line (comment-heavy source no longer misclassifies as `error`);
  initial `fill_pct` is derived from `INITIAL_RATIO_EMA` so the two can
  never diverge; `AppState` fields are documented by category and the
  std-Mutex-never-across-await rule is stated next to the fields.
- **Chore (style/classification)**: rustfmt spacing normalized; classification
  and UML docs refreshed for binary 1.5.0 / plugin 2.2.0.

`x86_64-unknown-linux-gnu`, `x86_64-pc-windows-msvc`) stages, per target, the
`aphrodite` binary + `libaphrodite_hermes` dylib + a `SHA256SUMS-<target>.txt`
