## Aphrodite v1.4.6 💋 Plugin v2.1.4

### Summary

v1.4.6 ships the chain-split CCR engine - a consequence-driven teaching loop
with an adaptive chain-split threshold plus fine-grained splitting for chained
shell commands (opt-in, `chain_split = false` in shipped config) - and honest
previews end-to-end: `preview_max_chars` is wired through every path
(env > TOML > default 120), the `ok`-collapse is gone, the caller's type hint
wins, and build/error/lint/log arms surface real lines with a truthful
`total_count`. The FFI layer is hardened (generated `_bindings.py` via
cbindgen → ctypesgen → `finalize_bindings.py`, pointer-width restype
enforcement, subprocess probe so a faulting dylib degrades to "plugin
disabled" instead of crashing the gateway), and the plugin relocates every
runtime artifact to the canonical `~/.hermes/aphrodite` home with a
self-healing layout checker. Released plugin-first: **plugins/aphrodite
v2.1.4** was tagged before the parent tag, so the parent's gitlink references
a released plugin commit and the plugin's `BINARY_VERSION` (1.4.6) points at
assets that already exist. Binary `1.4.5 → 1.4.6`, plugin `2.1.3 → 2.1.4`.

### Changes

- **Feature (chain-split CCR)**: Tier 1 teaching loop with consequence-driven
  adaptive chain-split threshold (`85771ee`); fine-grained chain splitting for
  chained shell commands (`475917d`); opt-in OFF by default in shipped config
  (invariant D2).
- **Feature (previews)**: `preview_max_chars` cap wired on every path
  (`6ebdf35`, `fe374d3`); preview test-leakage prevention (`d6634e8`);
  build/error/lint/log arms surface real lines, `total_count` is real
  (Issue #11 preview machinery).
- **Fix (FFI)**: SIGSEGV class closed - probe sentinel, forced `c_void_p`
  restype, same-handle free, `free_string` argtypes fix; generated
  `_bindings.py` (cbindgen → ctypesgen) validated by a pure-AST contract
  checker at build time (`finalize_bindings.py`); subprocess smoke-test
  refuses a faulting dylib before ctypes loads it in-process.
- **Fix (setup)**: `aphrodite setup` registers the plugin with Hermes and
  provides manual linking instructions (`4200542`).
- **Fix (config)**: make API key optional at parse time and enforce it for
  proxy launches; publish-condition fixes on tags.
- **Chore (config)**: shipped config templates refreshed, provider-specific
  defaults dropped (`b028328`); compression thresholds raised and engine
  compression enabled by default (`621e54b`).
- **Plugin v2.1.4**: runtime artifacts relocated to `~/.hermes/aphrodite`
  (binaries, directives, ccr.db, logs) - the plugin directory is now a thin
  registration shim (`36f4f14`); self-healing layout checker
  (`layout_check.py` + `layout_schema.json`); skills/directives ship dev-side
  / binary-provided; legacy plugin-dir paths kept as warning-flagged
  fallbacks; `_check_version_published` warns before `download.sh` when the
  pinned `BINARY_VERSION` points at a release with no assets.
- **Docs**: README/docs rewritten for the canonical runtime layout and
  loader-only role; docs converted to absolute `tree/Current` URLs; internal
  fork-divergence docs (`APHRODITE-HEADROOM.md`, `HEADROOM-FORK-DIFF.md`,
  `hermes-tool-output-schemas.md`), `Maintain/` installers, `.githooks/`,
  and editor tooling configs removed from the release line.
