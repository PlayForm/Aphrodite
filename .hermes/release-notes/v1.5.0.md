## Aphrodite v1.5.0 💋 Plugin v2.2.0

### Summary

v1.5.0 is the edition-2024 + atomization release: the crate moves to the
nightly toolchain and Rust 2024 edition (unsafe-attr exports, let-chains), the
flat `src/*.rs` files are promoted into per-item module trees (`state/`,
`preview/`, `directives/`, `marker/`, `resolve/`, `setup/`,
`struct_extract/`, `config/`), and the `chrono` dependency is dropped. It
adds the `aphrodite_debug` tool (per-session debug toggle that survives dylib
hot-reloads via a persisted session id), restructures the dev skill system
into canonical contract skills with a governance layer, and lands two full
inspection waves of correctness fixes across the state engine, catalog,
session lifecycle, hooks pipeline, proxy, retrieve, and config loader. The
README gains a real-world savings analysis with compression metrics.
Binary `1.4.6 → 1.5.0`, plugin `2.1.4 → 2.2.0`.

### Changes

- **Migration (edition-2024)**: workspace toolchain moved to latest nightly;
  `no_mangle` exports migrated to edition-2024 `unsafe` attribute syntax;
  nested conditionals converted to let-chains; `vendor/headroom` bumped to
  restore closure signatures; FFI contract checker taught the edition-2024
  attribute form.
- **Chore (headroom publication)**: `vendor/headroom` was bumped in the tree
  to 02706ea1 (upstream sync + nightly-toolchain migration). The crates.io
  publication of `aphrodite-headroom-core` stayed at 0.1.2 (July 2026).
  None of the fork's accumulated changes shipped on crates.io in 1.5.0;
  1.5.1 will publish them as 0.1.3.
- **Refactor (atomization)**: flat module files converted to directory-based
  modules, then atomized into per-item module trees; docs and scripts
  re-pointed at the new layout.
- **Feature (debug)**: `aphrodite_debug` tool toggles per-session debug
  output; session id persists across dylib hot-reloads and stays scoped to
  the current turn's session.
- **Refactor (deps)**: `chrono` dependency removed; `lru` becomes an
  unconditional dependency of the state engine (inline-store LRU).
- **Docs (skills)**: skill system restructured into canonical contract
  skills with a governance layer; README savings analysis with real-world
  compression metrics.
- **Fix (inspection wave 1 - state/catalog/session)**: inline-store LRU
  promotion is O(1) via the `lru` crate order cache (was O(n) `retain`);
  `chain_split_enabled` struct default now matches the shipped config
  default (false); `recent_markers` is a `VecDeque` with O(1) front
  eviction; ring caps become named constants; `always_survive` counts only
  present sections; catalog `by_type` is deterministic (`BTreeMap`); the
  file-delta summary selects genuinely new files in insertion order;
  `chain_split_min_segments` resets to the configured floor on session
  start; `post_llm_call` archives the largest marker of the turn; the
  catalog table reports entries beyond its 20-row window; directive
  truncation uses a consistent char-count unit.
- **Fix (inspection wave 2 - proxy/retrieve/config)**: poisoned `inline_ccr`
  lock returns HTTP 500 instead of a silent miss; `get_bool` accepts
  uppercase/mixed-case values; a found-but-broken `aphrodite.toml` now warns
  instead of being skipped silently; the missing-`$HOME` fallback warns
  instead of silently writing the CCR database to a volatile location;
  `body_wants_stream` gets a byte-exact fast path; content-type detection
  requires error markers at the start of the first line; initial `fill_pct`
  is derived from `INITIAL_RATIO_EMA`; `AppState` fields are documented by
  category and the std-Mutex-never-across-await rule is stated next to the
  fields.
- **Fix (hermes)**: the hermes test helper uses `VecDeque::back()` for
  `recent_markers` (`.last()` does not exist on `VecDeque`); unnecessary
  `unsafe` block removed from the C-string teardown path.
- **Chore (style/classification)**: rustfmt spacing normalized; classification
  and UML docs refreshed for binary 1.5.0 / plugin 2.2.0.

### What Ships

Build.yml's 4-target matrix (`aarch64-apple-darwin`, `x86_64-apple-darwin`,
`x86_64-unknown-linux-gnu`, `x86_64-pc-windows-msvc`) stages, per target, the
`aphrodite` binary + `libaphrodite_hermes` dylib + a `SHA256SUMS-<target>.txt`
(4 targets × 3 files = 12 artifacts).
