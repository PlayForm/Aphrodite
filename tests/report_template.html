Inline - Python Library CCR

headroom.compress() called in-process on the accumulated session cache plus a new randomized tool output. CCR markers are LLM-native compressed references - the model understands them without decompression. Zero HTTP, zero API cost.

Proxy - headroom → DeepSeek billed

HTTP POST through headroom proxy (port 8787) with accumulated session context. These are actual billed prompt tokens as reported by the DeepSeek API - the ground-truth cost metric.

Pipeline: HTTP POST → CacheAligner → ContentRouter → SmartCrusher → Kompress → Cache → upstream POST to DeepSeek. The proxy handles CCR markers, caching, and rate limiting transparently. Tool messages from the cache are filtered out (DeepSeek does not accept role=tool). Completion tokens are capped at 50.
